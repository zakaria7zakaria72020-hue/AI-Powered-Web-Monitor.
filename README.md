# 🌐 AI-Powered Web Monitor (Scraper)

### 🎯 Overview
A Python-based monitoring tool designed to track real-time changes on websites (prices, news, or stock levels). It automates the "checking" process, saving hours of manual browsing.

### 🚀 Key Capabilities
- **Web Scraping:** Extracts specific data points using BeautifulSoup.
- **Smart Alerts:** Triggers notifications only when specific conditions are met (e.g., Price Drop).
- **Automation Ready:** Can be scheduled to run every hour on PythonAnywhere.

### 🛠 Tech Stack
- **Python** (Requests, BeautifulSoup)
- **Logic:** Conditional monitoring & Alerting systems.
